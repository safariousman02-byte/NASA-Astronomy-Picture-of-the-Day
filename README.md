

# Astronomy Picture of the Day (APOD)

A sleek, modern web application designed to showcase daily space imagery and astronomy highlights, complete with a clean dark-mode interface and navigation controls to browse across different dates.

---

## Features

* **Daily Astronomical Showcase:** Displays high-resolution photography, titles, and detailed scientific descriptions of celestial events, planets, and space landscapes.
* **Interactive Date Navigation:** Equipped with **<- Previous** and **Next ->** buttons to seamlessly browse through past and upcoming entries.
* **Immersive Dark Theme:** Styled with a polished dark-mode aesthetic tailored for optimal viewing of space visuals.
* **Responsive Layout:** Designed to adapt fluidly across various desktop and mobile screen sizes.

---

## Technologies Used

* **HTML5:** Semantic structure for the content layout.
* **CSS3:** Custom styling, dark mode color schemes, and flexbox/grid alignments.
* **JavaScript (ES6+):** Dynamic content rendering and event handling for pagination/navigation.
